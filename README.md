# ⚔ THE WATCHER 4 — Browser Demo

> *Wild Hunt? More like Mild Flirt.™*
> A Totally Legally Distinct Parody Demo

Play as **Gerald of Riviera** — professional monster slayer, amateur bath
enthusiast, owner of exactly one facial expression — as he hacks through a
swamp full of moist personalities, flirts his way through a candle-lit
tavern, and faces the most terrifying boss on the Continent: **The Tax
Collector of Novigrad**.

## ▶ How to Play

No build, no install, no DRM launcher with three mandatory accounts.
Just open the file:

```
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

Or serve it if you're fancy:

```
python3 -m http.server 8000
# then visit http://localhost:8000
```

## 🎮 Controls

| Key | Action |
|-----|--------|
| `WASD` / arrows | Move |
| `SPACE` / click | Swing sword (aims at mouse) |
| `Q` | **Igni** — cone of fire, solves most problems |
| `E` | **Quen** — golden shield, absorbs one hit |
| `R` | Summon Roach (results may vary, pathfinding sold separately) |

## 🗺 Demo Contents

- **3 waves of monsters** — drowners, nekkers, and ghouls who are going through something
- **A tavern romance scene** with two sorceresses, one unflappable bartender, and one (1) extremely eligible bathtub — saucy but tasteful, fade-to-black guaranteed
- **A boss fight** against weaponized bureaucracy (weakness: receipts)
- **A charm rating system** ranging from *Emotionally Constipated (canon)* to *Certified Swamp Casanova*
